# LuminaPlus 丢包口径适配（2026-11-20）

参考版本：volcano-1025/CFSM-Theme-LuminaPlus v1.2.24，源码提交 `391dc27`。

- ping/loss 先按时间戳配对；本地连续实测覆盖区间优先，后端窗口补未覆盖时段。
- 样本按覆盖时长计权（15 秒一份），按桶中点投影，短事件仍归入所在桶。
- 固定 20 桶；优先使用公开配置的窗口小时数，不把缓冲额外保留的 15 分钟算进固定窗口。
- 丢包数字按柱带桶的样本份数加权，不对 20 个百分比简单平均；延迟数字取最新成功探测。
- 丢包沿用连续 HSL 渐变；去掉整排柱子的额外 80% 透明度，深色延迟高值红对齐为 #f47067。
- 离线时在最后上报时刻截断，完整离线桶两排均标红，但状态红不作为人为制造的测量值参与平均。
- 当前探针公开快照下，两台节点三网共 12 组后端窗口／混合样本模型的丢包桶值、权重和平均值与参考原函数逐项一致。
- 仅修改主题；不修改 CFSM 后端、VPS 或正在使用的线上主题设置。

源码核心：`src/domain/probe-lumina.ts`，许可：`LICENSE-LuminaPlus`。
